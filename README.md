# 习惯收藏库 · awesome-habits

关于习惯，只收经过验证的：权威书籍、核心方法、经典金句、实用工具。

> 市面上讲习惯的内容大多在重复同一句话：「坚持就是胜利」。
> 但真正改变过几百万人行为的，是福格的行为公式、杜希格的习惯回路、克利尔的四大法则。
> 这份收藏库只收**有出处、有方法、能落地**的东西。收集者读过福格《Tiny Habits》、克利尔《Atomic Habits》、杜希格《The Power of Habit》等书，从中筛出真正值得反复看的。

## 取舍标准

- **有出处，不道听途说**：每条方法都标注来自哪本书、哪位研究者，不收录"网上说"的二手鸡汤。
- **有方法，不讲玄学**：能照着做的才是方法。只说"要有毅力"的不收。
- **可落地，不悬浮**：习惯的成败在环境设计与行为设计，不在口号。
- **中英对照**：书名、金句保留原文，中文世界可直接查阅。

## 核心速览（30 秒入门）

习惯领域最重要的三个框架，先把这三个记住，其余都是细节：

1. **福格行为模型**（BJ Fogg，《Tiny Habits》）：`行为 = 动机 × 能力 × 提示`
   行为没发生，不是意志力问题，是三者缺一。缺哪个补哪个，但**永远先补能力**：把行为缩小到「小得不可能失败」。

2. **习惯回路**（Charles Duhigg，《The Power of Habit》）：`提示 → 惯常行为 → 奖励`
   改变习惯不是删除回路，是**保留提示和奖励，替换中间的惯常行为**。

3. **四大法则**（James Clear，《Atomic Habits》）：让习惯**显而易见、有吸引力、简便易行、令人愉悦**。
   反过来，戒坏习惯：让它隐形、无趣、困难、令人不快。

**再加一条底层认知**：习惯养成的关键不是时间（21 天是谣言），而是**频率和情绪**。每次完成后的「庆祝」会把行为焊进大脑，因为大脑需要奖励才愿意重复。
